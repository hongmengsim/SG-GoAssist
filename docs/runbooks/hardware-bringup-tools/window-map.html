Bring-up window map

Pi #1 (AV-095-01) at goassist-pi1.local. Backend on this PC at 172.20.10.3:3000. The kind of window is shown by its border and a word tag, never by colour alone: solid = this PC, double = the Pi, dashed = browser.

Rules that stop the confusion.
  • One-off commands (scp, checks) go in the SCRATCH window only. Do not open a new window for each one.
  • Name each window when you open it with its title line below.
  • The agent and the camera live view cannot run at the same time: only one program can use the camera.
  • Never paste secrets, the operator token, or the status page's #code into chat.
  • Secrets are copied from window 4 (SCRATCH), on demand, the same way for both: Set-Clipboard $env:OPERATOR_API_TOKEN for the console page, Set-Clipboard $env:DEVICE_SHARED_SECRET for window 5. Paste, then Set-Clipboard $null. There is no timed clipboard.
  • One-shot: bringup.ps1 opens windows 1 to 6 as named tabs in one Windows Terminal window.

On this PC (4 PowerShell windows)

This PC1. BACKEND
What it isThe server. The Pi and the console both talk to it. Holds the device secret and operator token in its environment.
Name the window
$Host.UI.RawUI.WindowTitle = 'BACKEND (this PC)'
Start by hand (generates fresh secrets; the one-shot launcher does this for you) 
cd D:\D\Claude\SG-GoAssist-hardware; $b = New-Object byte[] 32; $g = [Security.Cryptography.RandomNumberGenerator]::Create(); $g.GetBytes($b); $env:DEVICE_SHARED_SECRET = [BitConverter]::ToString($b).Replace('-','').ToLower(); $g.GetBytes($b); $env:OPERATOR_API_TOKEN = [BitConverter]::ToString($b).Replace('-','').ToLower(); $env:GOASSIST_AUTO_ACK = 'off'; $env:GOASSIST_DATA_DIR = '.runtime\hw'; npm.cmd start --workspace "@buspass/backend"
StopCtrl+C. The secrets stay in this window until you close it, so you can copy the token again with Set-Clipboard $env:OPERATOR_API_TOKEN.
After a restart with new secretsCopy the new device secret from window 4 and paste it into the Pi (window 5) again.
This PC2. CONSOLE SERVER
What it isServes the operator console page on port 5173. Needed only while the console tab is open.
Start
$Host.UI.RawUI.WindowTitle = 'CONSOLE SERVER (this PC)'; cd D:\D\Claude\SG-GoAssist-hardware; npm.cmd run console
StopCtrl+C.
This PC3. TUNNEL
What it isA private pipe to the Pi's own web pages, so they are not open on the network. One window forwards both: the agent's status page (8770) and, when the agent is stopped, the camera live view (8780).
Start
$Host.UI.RawUI.WindowTitle = 'TUNNEL to Pi'; ssh -N -L 8770:127.0.0.1:8770 -L 8780:127.0.0.1:8780 pi@goassist-pi1.local
StopCtrl+C. It prints nothing while it works: that is normal.
This PC4. SCRATCH
What it isThe only place for one-off commands: scp, copying files, Set-Clipboard $null, git. Reuse it. Do not keep it running anything.
Start
$Host.UI.RawUI.WindowTitle = 'SCRATCH (this PC)'; cd D:\D\Claude\SG-GoAssist-hardware

On the Pi (2 SSH windows)

The Pi5. PI AGENT
What it isRuns the bus agent. You type its commands here (status, calibrate, arrive 18331). Holds the device secret in this shell only.
Open and start 
ssh pi@goassist-pi1.local
read -rs DEVICE_SHARED_SECRET; export DEVICE_SHARED_SECRET
cd ~/SG-GoAssist/pi/bus-agent && python3 -m bus_agent --real --config agent.json --status-port 8770
StopCtrl+C. Start it again in the same window and the secret is still set.
Do not use it foranything else. While the agent runs it owns the camera and the ESP32's serial port.
The Pi6. PI CHECKS
What it isA second SSH window for read-only checks while the agent runs: power, USB, disk.
Open

Useful
vcgencmd get_throttled; dmesg | grep -ci over-current; dmesg | grep -c "USB disconnect"

What goes where

  • "Is the Pi's decision reaching the backend?" → tab A, and the audit file backend\.runtime\hw\audit.ndjson.
  • "Why is the ramp halted?" → tab B, or tab A once diagnostics are added to the console.
  • "Is the ESP32 or the power dropping?" → window 6.
  • "Copy a file to the Pi" → window 4 (scp).
